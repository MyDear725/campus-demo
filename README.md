# 风起 · 校园 / Campus Echo

本地单人第三人称 3D 校园探索核心 Demo。以大连理工大学开发区校区为原型，使用学校官方地图中的开发区校区地物轮廓重建布局；道路参考用户提供的卫星地图补绘。建筑高度与外立面为风格化示意，不是实景测绘。

## 启动

Windows 双击 `启动校园Demo.cmd`。首次缺少依赖时需要网络下载 Three.js。安装完成后可断网运行。

也可以在此目录运行 `npm install`，然后 `npm start`，用桌面浏览器打开 http://127.0.0.1:4173 。需要 Node.js 和支持 WebGL 2 的浏览器。不要直接双击 index.html。

## 试玩路线

从南门出发，沿信息楼西侧步道到书韵广场找小岚。分别在图书馆前、涌泉湖畔、西北田径场收集三枚记忆，回书韵广场交付。可经湖东园路和连接通道到学府大街东侧生活区。完成后可继续探索。

任务进度保存在当前浏览器的 localStorage。暂停菜单支持重新开始任务和切换画面质量。角色位置不保存，刷新后从入口开始。建筑外墙有碰撞，当前不开放室内、攀爬或战斗。

支持鼠标锁定的浏览器可连续转动视角；内嵌浏览器若不允许锁定，会显示提示；请使用外部 Chrome 或 Edge 浏览器体验无限转向。暂停、对话和结算时视角停止跟随，鼠标恢复为普通指针。

## 内容与技术

- Three.js 0.180.0（MIT）；其许可证位于 node_modules/three/LICENSE。
- 建筑和湖泊轮廓来自学校公开地图；建筑外观、植被、角色、道具、任务文本与界面由本项目程序化创建，无外部商业游戏素材。
- 校园连续场景、第三人称镜头避障、角色运动与动画、碰撞、跳跃、任务状态机、地图、存档、音效。
- 不依赖在线模型服务或 CDN。所有游戏逻辑在本地运行。
- `npm test` 验证墙体碰撞、边界、任务流程与损坏存档恢复。
- 打开 `http://127.0.0.1:4173/?qa=1` 可运行完整任务集成检查，使用与游戏相同的移动、碰撞和交互函数走完路径，不覆盖玩家存档。检查结果见 `tests/browser-results.txt`。
- `window.campusDemo.getState()` 提供只读运行诊断。

## Blender 角色

新版校园旅人采用 Blender 4.5.9 建模与骨骼绑定，通过 GLB 加载到游戏；三名角色共享网格，NPC 使用不同外套配色。八个动画片段为 Idle / Walk / Run / Jump / Fall / Land / Tired / Talk，分别对应待机、步行、奔跑、起跳、下落、落地缓冲、疲劳喘息和对话手势。

走跑循环保持脚步相位并平滑混合，体力耗尽不会逐帧重启动画。按住 Shift 到体力耗尽后，持续步行约 1.8 秒恢复到门槛再奔跑；疲劳时停下会喘息。动画依据碰撞后的实际位移判断是否移动。暂停会冻结角色，对话时角色继续待机，小岚播放手势和嘴部动作。

Blender 源文件包含 Blink / Smile / Tired / Talk 四个面部形态键；游戏自动眨眼、在对话和完成任务时微笑、疲劳时降低眼睑。嘴部变化是简单的程序动画，尚未提供语音口型同步。预览页可单独检查各动作与表情。

- 可编辑源文件：`art/character/campus-traveler.blend`，包含角色、18 根骨骼、动作和摄影棚灯光。
- 游戏资产：`assets/characters/campus-traveler.glb`。
- 正反面渲染：`art/character/traveler-front.png`、`traveler-back.png`。
- 独立预览：打开 `http://127.0.0.1:4173/character.html`，可查看正背面、面部和动作。
- 重建脚本：`art/character/build_character.py`。从工作区运行 `.tools/blender-4.5.9-windows-x64/blender.exe --background --python campus-demo/art/character/build_character.py`。

这是用 Blender Python 脚本制作的原创风格化模型，支持后续在 Blender 中继续手工调整。当前采用材质配色和面部形态键，没有手绘皮肤贴图；尚未加入脚掌 IK 或布料模拟，贴地与步幅仍可继续打磨。

本版用于验证核心交互和美术方向。后续可据实拍资料调整场景，也可将玩法迁移至 Unity 等引擎。浏览器代码不能直接作为 Unity 项目使用。

## 开发区校区地图重建（2026-10-12）

- 鸟瞰与平面预览：`http://127.0.0.1:4173/map.html`，支持三维旋转、正北俯视、平面地图。
- 校区确认：[学校地图](http://map.dlut.edu.cn/#/home) 的公开校区接口返回 `77298 / 开发区校区`；未使用主校区或盘锦校区。
- 数据依据：`/openmap/mapi/campus/v1`、`/openmap/mapi/bd/v1/bound`。保留的开发区原始轮廓位于 `art/map-reference/development-campus-bounds.json`；运行时数据位于 `campus-data.js`，无需联网。
- 27 个地物含北部 A/B/C 教学楼、西北运动场与体育馆、锦屏山、思源湖、涌泉湖、综合楼、东南图书馆与信息楼、书韵广场，以及学府大街东侧宿舍/食堂/活动中心。
- 坐标原点为官方开发区中心，北为 -Z，东为 +X。按中心纬度作局部平面投影，水平距离统一乘 0.5。游戏距离提示为游戏米，不是实际步行导航距离。高度没有来源数据，采用 7–17 游戏米示意。
- 道路以用户卫星截图为依据，手工补绘中心线；与官方轮廓结合后对关键步行路线作碰撞检查。并非精确 GIS 道路数据；生活区连接通道按平面道路处理，尚未建成立体天桥。
- 西南侧开发区第一中学及东侧居民区属于校外背景，没有误建成大学运动场。校区内建筑暂不开门进入；湖面与锦屏山区域暂不可进入。
- 官方地图与截图部分宿舍名称存在差异，本版沿用官方名称，后续可按校区现行标识调整。官方站点交互页面在本次环境超时，数据通过该站公开接口取得并限定为开发区范围。
- 三维场景、小地图和鸟瞰页共用地物坐标。M 可打开大地图；`npm test` 覆盖实际方位、湖岸防穿越、任务点落位与全程步行连通。

## 校园环境升级（2026-10-12）

- `foliage.js`：四组原创程序化枝干与叶片模型，实例化渲染、叶片透明裁切、风摆及对应动态阴影；道路林木和山坡林木分开布置。
- `nature-materials.js`：本地生成沥青颗粒、步道砖缝、树皮、草地和石材纹理，不依赖外部图片下载。
- `landscape.js`：连续道路带、路缘石、标线和斑马线，湖岸石块、芦苇和木椅，平滑锦屏山及示意远山。道路标线、植被品种和远山形状为美术设计，并非实地测绘。
- 两座湖共用一次 512×512 平面反射，显示天空、岸边建筑和树木倒影；法线波纹随时间缓慢变化。流畅画质关闭平面反射与阴影，改用低开销环境反射。
- `atmosphere.js`：大气散射天空、程序化流动云和距离雾，并为玻璃等材质提供天空环境光。
- 地图预览页增加“湖畔水岸 / 林荫道路 / 天空与远山”近景入口。普通游戏页仍按原有鼠标、WASD 和 Esc 操作。
- 新增种植碰撞回归：直线路线、键盘斜行接直行路线都预留通道；树木不能阻断任务和生活区路线。

## 花境与地被升级（2026-10-13）

- 新增 `campus-gardens.js`：入口与沿路混合花境、紫色花穗和浅色小花、低矮灌木、自然草丛、树下土圈与零散落叶。植物为原创程序化几何，种植方案为美术设计，并非校区实地植物调查。
- 草坪采用世界坐标下的深浅变化，减少整片纯色地面的感觉；花草保留不同高度、朝向和轻微风摆。
- 地图预览页“近看环境”中新增“入口花境”；游戏与地图共用相同种植数据。
- 植物按 48 米区域实例化，近处完整显示，远处渐隐与剔除；流畅画质降低植物密度和显示距离，保留花坛土壤与边界。
- 种植区域避开建筑、道路、人行道、环湖步道和交互点；不新增阻挡玩家的花草碰撞体。
- 预览图：`art/environment/flower-garden-preview.png` 和 `art/environment/lakeside-gardens-preview.png`。

## 道路分级与临街边界（2026-10-13）

- `campus-layout.js` 中每条道路具有 `external / main / secondary` 分类，分别对应校外公路、校内主路和校内辅路；不再只按宽度猜测用途。
- 校外公路：深色沥青、双黄中心线、白色边线及较宽路侧步道。校内主路：浅灰沥青、较疏的引导虚线及人行道。辅路：暖色铺砖、石材分隔带和窄边框，不画机动车中心线。
- `road-design.js` 统一绘制路面、接路口、路缘和过街标线；交叉口处断开标线与路缘，避免条带横穿通行空间。
- `campus-boundary.js` 提供临街围栏面板，三维场景、平面图与碰撞共用数据。围栏由矮石基座、立柱、压顶与金属栏杆组成；角色无法直接穿过。
- 南门、跨学府大街的生活区通道和既有生活区人行入口保留开口，南门与生活区连接口设置过街线；新增一段通向生活区人行入口的短辅路。
- 为避免内外道路与围栏相互挤压，北侧公路和南侧校内环路做小幅位置调整；围栏线路为参考已有校园布局的设计示意，未经地籍测量确认。
- 围栏碰撞先做范围筛选，再做线段距离检测，避免斜围栏使用过大的方形碰撞范围。花草与树干避让围栏，任务路线、主门和生活区通行均有回归检查。
- 预览页新增“临街围栏与公路 / 校内辅路 / 生活区连接口”；平面图使用三种路色并显示围栏与图例。
